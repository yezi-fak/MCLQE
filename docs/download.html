下载与安装步骤

  1. 下载压缩包：点上方「下载 Windows 版」按钮，获取 MCLQE-launcher-windows-x64.zip（约 61.6 MB）。
  2. 可选校验：用 PowerShell 计算 SHA256，与上方值逐字符比对，一致再继续。
  3. 解压到固定目录：右键解压到如 D:\MCLQE。建议非系统盘、路径不含特殊符号，便于备份与迁移。
  4. 双击启动：进入解压目录，双击启动程序即可打开主界面。首次启动会创建配置目录并检测 Java 环境。
  5. 选择游戏目录：默认目录为 D:\MCLQE\MCLQE，可在界面中切换或新增多个游戏目录。
  6. 登录并安装版本：可用微软正版账号登录，或直接使用离线模式；随后在版本列表中选择游戏版本下载安装，必要时一键安装 Fabric / Quilt / Forge / NeoForge 加载器。

校验与解压运行

下载完成后建议校验一次文件完整性，避免传输中断导致的解压失败。在文件所在目录打开 PowerShell：

Get-FileHash .\MCLQE-launcher-windows-x64.zip -Algorithm SHA256

输出应与下载页给出的 SHA256 完全一致。若不一致，删除文件重新下载。解压建议使用系统自带解压或 7-Zip，不要在压缩包内直接双击运行；启动程序需与同目录的运行库文件保持相对位置，单独拷出 exe 会无法启动。

绿色软件：删除目录即可完成卸载。存档与配置默认在游戏目录内，删除前请先备份 saves 文件夹。

常见安装问题

双击后没有反应，或窗口一闪就消失▾

多数情况是只复制了启动程序、丢掉了同目录的运行库文件。请确认整个压缩包已完整解压，并在解压目录内启动。若仍无反应，查看同目录的日志文件，或以命令行运行启动程序查看报错信息。

提示缺少 Java / 找不到运行时▾

压缩包已内置运行时不需额外安装。若你手动指定了 JDK，请按系统要求表核对版本：1.16.5 及更早用 JDK 8，1.17–1.20.4 用 JDK 17，1.20.5 / 1.21+ 用 JDK 21。也可在设置中改回「使用内置运行时」。

解压或启动时提示路径错误▾

把程序放在纯英文路径下，例如 D:\MCLQE，避免中文、空格与过深层级；同时确认该目录有写入权限（不要放在 C:\Program Files 下）。

被杀毒软件拦截或提示有风险▾

未签名的开源程序常被启发式误报。请从本站按钮或官方 GitHub Releases 下载，并用 SHA256 校验；确认一致后加入信任列表即可。来源不明的二次打包版本不要运行。

游戏版本或模组下载很慢▾

游戏本体资源来自 Mojang 官方源，模组来自 Modrinth 官方接口，速度受网络线路影响。可换时段重试；已下载完成的文件会复用，不会重复拉取。

如何更新到新版本▾

下载新版压缩包，解压后覆盖到原目录即可；存档、模组与配置都在游戏目录中，不在启动器目录内，不会被覆盖。更新前建议先备份游戏目录。
