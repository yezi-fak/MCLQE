Questions

Q1MCLQE 是什么？▾

MCLQE 是一款基于 Java 21 + JavaFX 21 开发的开源 Minecraft Java 版启动器，运行于 Windows 10 / 11 64 位，解压即用。

它把版本管理、模组与加载器安装、微软正版登录收在同一个深色界面里；本身不包含任何游戏本体文件，启动时下载的资源来自 Mojang 官方源。界面为 JavaFX 原生绘制，不内嵌浏览器内核，启动快、内存占用低。

Q2怎么下载和安装？▾

到 下载与安装 页或 GitHub Releases 下载 MCLQE-launcher-windows-x64.zip（约 61.6 MB），解压到任意目录（如 D:\MCLQE），双击目录内的启动程序即可。

  • 免安装，不需要管理员权限，不写注册表。
  • 压缩包内已带运行时，无需另行安装 Java。
  • 建议解压到非系统盘，且路径不含特殊字符，便于备份存档。
Q3需要什么 Java 版本？▾

启动器自带运行时，一般情况下不需要你单独安装 Java。若你想指定自己的 JDK，按游戏版本准备：

  • Minecraft 1.16.5 及更早 → JDK 8
  • Minecraft 1.17 – 1.20.4 → JDK 17
  • Minecraft 1.20.5 及 1.21 以上 → JDK 21

启动前启动器会异步检测 Java 环境，缺失或版本不匹配时会给出提示并引导下载对应运行时。

Q4和 HMCL、PCL 有什么区别？▾

MCLQE 的定位是轻量、干净、开箱即用：

  • JavaFX 原生界面，不内嵌浏览器内核；
  • 默认游戏目录固定为 D:\MCLQE\MCLQE，并支持多目录切换；
  • 模组通过 Modrinth 官方接口搜索并一键安装；
  • 加载器支持 Fabric / Quilt / Forge / NeoForge 一键部署。

如果你需要大量第三方下载镜像、整合包制作等更重的功能，HMCL 与 PCL2 更合适。三者互不冲突，可以同时安装，共用同一套游戏目录也不会破坏存档。

Q5模组怎么装？▾

在左侧「模组」面板搜索 Modrinth，选中后指定目标版本目录，启动器会自动解析依赖并下载到该版本的 mods 文件夹；也可以手动把 jar 拖进对应目录。

  • 模组必须匹配游戏版本与加载器类型；
  • Fabric / Quilt 的模组与 Forge / NeoForge 的模组不能混用；
  • 需要前置库（如 Fabric API）时，启动器会在依赖解析中提示。
Q6可以用微软正版账号登录吗？▾

可以。登录走微软标准 OAuth 设备码流程，登录后即以正版身份启动，可进入正版服务器；同时保留离线模式，本地游玩无需账号。

账号凭据与游戏配置只保存在本地目录，不会上传到任何第三方服务器。

Q7内存应该设置多少？▾

经验值是物理内存的 1/4 到 1/2：

  • 8 GB 内存 → 2048–3072 MB
  • 16 GB 内存 → 4096–6144 MB
  • 32 GB 及以上 → 6144–8192 MB

加光影或大型整合包时可再上调，但不要超过物理内存的一半，否则系统整体会卡。调整位置：设置 → 内存上限。

Q8启动报错怎么办？▾

先看启动器底部的状态提示，以及对应版本目录下的日志文件。常见原因与处理：

  • Java 版本不匹配：按 Q3 的版本对照表更换 JDK，或点「重新检测」；
  • 模组不兼容：暂时移出 mods 目录内的模组，再逐个加回定位；
  • 内存过大：调低内存上限后重试；
  • 目录无写入权限：把游戏目录移到非系统盘或用户目录下。

仍无法解决时，把日志附到 GitHub Issues。

Q9会收集我的隐私数据吗？▾

不会。启动器没有遥测，不收集行为数据，也不要求注册任何账号；账号凭据、游戏配置与日志都只存在本地目录。

仅在安装模组、安装加载器或检查更新时，会访问 Modrinth 与 GitHub 的公开接口获取版本信息。
