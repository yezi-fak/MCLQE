MCLQE

基于 Java 21 + JavaFX 的 Minecraft Java 版启动器。多版本管理、模组与加载器一键安装、微软正版登录，深色界面开箱即用。

Features

该有的都有，不该有的没有

只做启动器该做的事：把版本、模组、加载器和账号管好，界面保持干净。

▣

多实例与版本管理

独立游戏目录、多版本并存，切换版本不改动已有存档与配置。

↓

Modrinth 模组直装

内置搜索与依赖解析，选中即装，支持镜像源，无需手动搬运 jar。

⚙

加载器一键部署

Fabric、Quilt、Forge、NeoForge 版本列表实时拉取，按所选游戏版本自动匹配安装。

◎

微软正版登录

走标准 OAuth 设备码流程，同时支持离线模式，账号数据本地保存。

☕

Java 自动识别

按游戏版本判断所需 Java 版本，缺失时直接引导下载适配的运行时。

◐

深色原生界面

JavaFX 原生绘制，无内嵌浏览器内核，启动快、内存占用低。

Preview

界面预览

全部功能在同一套深色主题下展开，左边的实例列表到了右边就是可操作的版本卡片。
